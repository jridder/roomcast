# Changelog

## 0.1.0 — 2026-11-06

First release.

- Outputs: groups of AirPlay and Sendspin speakers, each a PipeWire sound device
- Left/right stereo pairs from any two speakers; Apple Home pairs suggested
- Sonos stereo pairing and separation
- Per-app routing that WirePlumber remembers
- Volume for outputs, pairs, speakers and apps, using the speaker's own
  volume where supported
- HomePod support through a User-Agent fix in a private copy of PipeWire's
  AirPlay module
- Sendspin bridge for the FutureProofHomes Satellite1, with a per-speaker
  delay to line it up with AirPlay speakers
- Top-panel menu (GNOME Shell extension)
